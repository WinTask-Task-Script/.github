# WinTask - Named script for a job on a PC you own

Steps should live in one named script on a PC you own. Reminder notes wait off the live desk.

## Session Card

| Slice | What you do in WinTask | What remains |
|-------|------------------------|--------------|
| Arrival | Open WinTask on a PC you own and name the automation desk | A titled task script |
| Focus | Keep one desktop job on a WinTask own PC | A short step list |
| Check | Read the steps before you replay a job you already do | A confirmed automation desk |
| Handoff | Leave the WinTask task script on that job | A note for the next visit |

## How WinTask Sits

WinTask does not replace the apps you already run on a PC you own. It sits beside them as a named task script for a WinTask desktop job you already do.

If two people share a PC, each keeps a WinTask automation desk of their own. Extra jobs wait for their own title instead of crowding the live script.

A first visit should be one short job you already run, then the same WinTask task script the next day. That is enough to see if the layout holds on a PC you own.

Work stays on your own desktop. Other people's screens stay off the live set.

## Traffic Light

| Signal | On the WinTask automation desk | What you do |
|--------|--------------------------------|-------------|
| Green | Named script, steps on a job you already do | Continue the same desktop job |
| Amber | Steps from two jobs mixed | Split the set before a large change |
| Red | No title, reminder notes everywhere | Stop and name the automation desk first |
| Clear | Handoff written, step list short | Close WinTask and leave the desk |

## Open Order

1. Open the last WinTask session on a PC you own, not a new empty script.
2. Read the task script and the last handoff.
3. Finish one visible step inside WinTask desktop job.
4. Write what changed on a job you already run, then close with fewer reminder notes than you found.
5. If the automation desk feels crowded, drop anything that belongs to a different WinTask job.
6. Leave the script on the same named WinTask own PC.

## After a Week

A week in WinTask is not a longer script pile. It is the same task script, a shorter step list, and a note that still makes sense on Monday.

Take finished jobs off the live set so the next visit starts on the WinTask automation desk that is still open.

Other programs stay where they are. WinTask only keeps the path back: script name, steps, desktop job, handoff.

## Sign-off

- [ ] The WinTask workspace name is short enough to scan

## Field Note

WinTask is easier to trust when the step list stays smaller than the reminder pile around it. Name the automation desk, keep the script on a job you already do, finish one visible step, and write what changed.

The same loop fits a shop desk or a shared computer. Open the last WinTask task script and continue. Do not rebuild the steps from scratch.
